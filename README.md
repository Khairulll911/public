# Portofolio Khairul Sudrajat

Portofolio statis berbasis React + Vite, siap di-deploy ke GitHub Pages.

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Hasil build berada di folder `dist/`.

## Deploy ke GitHub Pages

Workflow GitHub Actions di `.github/workflows/deploy.yml` akan melakukan build dan deploy otomatis setiap kali branch `main` diperbarui.
